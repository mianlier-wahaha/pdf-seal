# PDF 骑缝章

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-Hant.md)

一个原生 macOS 应用，为 PDF 文件加盖**电子骑缝章**与**正文章**。SwiftUI + PDFKit/CoreGraphics 实现，零第三方依赖，纯本地处理，不上传任何文件。

## 功能

### 骑缝章
- 缝位：右缝 / 左缝
- 页范围：全部页或指定起止页
- **上下偏移**：拖动滑杆实时调整章条在缝上的位置，多条骑缝章可错开互不覆盖
- 支持添加多条骑缝章实例，各自锁定印章、缝位、范围与偏移
- **首页占比加大**：首页占固定比例（默认 25%），可开启「内页占比控制」（内页默认 5%）
  - 内页占比控制开启：内页各占固定比例，**尾页取剩余部分并始终盖到印章最右侧**
  - 内页占比控制关闭：首尾页占比一致，内页平均分配剩余比例
  - 各页占比之和超过 100% 时自动以多份印章沿缝平铺
- **尾页内移**：尾页章条不贴页缘，向页心内移整章宽度的 1/3，贴近真实手工盖章位置
- 骑缝章条可**按页删除 / 恢复**（右键菜单）
- 骑缝章整体透明度可调

### 正文章
- 点击页面任意位置落章，支持多次添加多枚
- 选中章后：拖动移动位置、右下角控制点等比缩放
- 每枚章实例**锁定添加时的印章**，切换印章库互不影响
- 正文章可**按页删除 / 恢复**（右键菜单）
- `⌘Z` / `Ctrl+Z` 撤销上一次移动 / 缩放

### 水印
- 文本水印：内容、字体、字号、颜色、透明度、旋转角度可调
- 平铺模式（整页重复）或单页模式
- 页码范围过滤（仅指定页加水印），水印垫底、章盖其上

### 印章库
- 导入 PNG / JPG 图片创建电子章
- **白色转透明**：带容差阈值滑杆的实时预览，扫描件、拍照图均可处理
- 物理尺寸设定（厘米），支持锁定长宽比；同一枚章在不同纸张规格上保持实际打印大小
- **拖拽重排**印章顺序，或用 ↑ / ↓ 键重排；库栏宽度 150–420pt 可调
- 右键重命名；印章库持久化存储，重开应用自动恢复

### 预览与文件
- 页面缩放：双指捏合 / 输入框 / 预设（25%–200%）
- 页码跳转、底部状态栏
- 保存（覆盖原文件）/ 另存为 / 关闭
- 预览与导出所见即所得（含透明度）
- `Esc` 取消选中
- 界面语言：简体中文 / 繁體中文 / English

## 使用方法

1. 打开 PDF 文件（拖入窗口或 ⌘O）
2. 在右侧面板选择印章 → 设置缝位 / 页范围 / 占比等参数 → 点「添加」生成骑缝章；或直接点击页面落正文章
3. 预览确认位置与效果（可拖动、缩放、按页删除）
4. 保存或另存为即可导出

## 环境要求

- macOS 13.0 及以上
- Xcode Command Line Tools（`xcode-select --install`）

## 构建与运行

```bash
# 方式一：命令行直接运行
swift run PDFSeal

# 方式二：打包成 .app（同时生成 release/ 下的 zip 与 dmg）
./scripts/make_app.sh
```

> 注意：macOS 新版 SwiftPM 沙箱与本机策略可能冲突，构建需带 `--disable-sandbox`（脚本已处理）。

## 项目结构

```
Sources/
├── SealCore/    # 盖章引擎：骑缝/正章几何计算、PDF 导出、水印、测试资产
├── PDFSeal/     # SwiftUI 应用界面
└── SealTool/    # 无头验证 CLI（生成测试 PDF、盖章、渲染比对）
scripts/         # 打包脚本（.app / zip / dmg）与图标生成
```

## 技术要点

- 盖章以 CoreGraphics 原生矢量绘制贴片，**不栅格化**，生成文件体积小、文字可选中
- 正确处理页面 `/Rotate` 旋转：旋转页的骑缝章按显示方向计算
- 采用「按页面尺寸分组 → 临时 PDF → PDFKit 按页序合并」方案，规避 macOS 26 上 per-page MediaBox 不生效的问题
