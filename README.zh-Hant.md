# PDF 騎縫章

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-Hant.md)

一款原生 macOS 應用，為 PDF 文件加蓋**電子騎縫章**與**正文印章**。基於 SwiftUI + PDFKit/CoreGraphics 構建，零第三方依賴，純本地處理，不上傳任何文件。

## 功能

### 騎縫章
- 縫位：右縫 / 左縫
- 頁面範圍：全部頁面或指定起止頁
- **上下偏移**：拖動滑桿即時調整章條在縫上的位置，多條騎縫章可錯開互不覆蓋
- 支援新增多條騎縫章實例，各自鎖定印章、縫位、範圍與偏移
- **首頁占比加大**：首頁占固定比例（預設 25%），可開啟「內頁占比控制」（內頁預設 5%）
  - 內頁占比控制開啟：內頁各占固定比例，**尾頁取剩餘部分並始終蓋到印章最右側**
  - 內頁占比控制關閉：首尾頁占比一致，內頁平均分配剩餘比例
  - 各頁占比之和超過 100% 時自動以多份印章沿縫平鋪
- **尾頁內移**：尾頁章條不貼頁緣，向頁心內移整章寬度的 1/3，貼近真實手工蓋章位置
- 騎縫章條可**按頁刪除 / 還原**（右鍵選單）
- 騎縫章整體透明度可調

### 正文印章
- 點擊頁面任意位置落章，可連續新增多枚
- 選取印章後：拖曳移動位置、右下角控制點等比縮放
- 每枚印章實例**鎖定新增時的印章**，切換印章庫互不影響
- 正文印章可**按頁刪除 / 還原**（右鍵選單）
- `⌘Z` / `Ctrl+Z` 復原上一次移動 / 縮放

### 浮水印
- 文字浮水印：內容、字體、字號、顏色、透明度、旋轉角度可調
- 平鋪模式（整頁重複）或單頁模式
- 頁碼範圍過濾（僅指定頁加浮水印），浮水印墊底、章蓋其上

### 印章庫
- 匯入 PNG / JPG 圖片建立電子印章
- **白色轉透明**：附容錯閾值滑桿的即時預覽，掃描件、拍照圖均可處理
- 物理尺寸設定（公分），支援鎖定長寬比；同一枚印章在不同紙張規格上保持實際列印大小
- **拖曳重排**印章順序，或用 ↑ / ↓ 鍵重排；庫欄寬度 150–420pt 可調
- 右鍵重新命名；印章庫持久化儲存，重開應用自動恢復

### 預覽與文件
- 頁面縮放：雙指捏合 / 輸入框 / 預設（25%–200%）
- 頁碼跳轉、底部狀態列
- 儲存（覆蓋原文件）/ 另存為 / 關閉
- 預覽與匯出所見即所得（含透明度）
- `Esc` 取消選取
- 介面語言：简体中文 / 繁體中文 / English

## 使用方法

1. 開啟 PDF 文件（拖入視窗或 ⌘O）
2. 在右側面板選擇印章 → 設定縫位 / 頁面範圍 / 占比等參數 → 點「新增」產生騎縫章；或直接點擊頁面落正文印章
3. 預覽確認位置與效果（可拖曳、縮放、按頁刪除）
4. 儲存或另存為即可匯出

## 下載安裝

倉庫內直接提供編譯好的安裝包（macOS Apple Silicon）：

- [Releases 頁面下載](https://github.com/mianlier-wahaha/pdf-seal/releases/latest) —— `PDF騎縫章.dmg`（標準安裝映像，打開後拖入「應用程式」）或 `PDF騎縫章.zip`（免安裝壓縮包），由 CI 自動構建發布

## 環境需求

- macOS 13.0 以上
- Xcode Command Line Tools（`xcode-select --install`）

## 建置與執行

```bash
# 方式一：命令列直接執行
swift run PDFSeal

# 方式二：打包成 .app（同時產生 release/ 下的 zip 與 dmg）
./scripts/make_app.sh
```

> 注意：新版 macOS SwiftPM 沙箱與本機策略可能衝突，建置需帶 `--disable-sandbox`（腳本已處理）。

## 專案結構

```
Sources/
├── SealCore/    # 蓋章引擎：騎縫/正文幾何計算、PDF 匯出、浮水印、測試資產
├── PDFSeal/     # SwiftUI 應用介面
└── SealTool/    # 無頭驗證 CLI（產生測試 PDF、蓋章、渲染比對）
scripts/         # 打包腳本（.app / zip / dmg）與圖示產生
```

## 技術要點

- 蓋章以 CoreGraphics 原生向量繪製貼片，**不點陣化**，產生檔案體積小、文字可選取
- 正確處理頁面 `/Rotate` 旋轉：旋轉頁的騎縫章按顯示方向計算
- 採用「按頁面尺寸分組 → 暫存 PDF → PDFKit 按頁序合併」方案，規避 macOS 26 上 per-page MediaBox 不生效的問題
